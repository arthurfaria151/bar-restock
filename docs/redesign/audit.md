# Redesign audit

Snapshot of `main` at `6e47cc2`, taken before the redesign.

## Stack

| Area | What it is |
|---|---|
| Framework | None. Plain HTML + one classic script (`app.js`, an IIFE). No build step, no `package.json`. |
| Styling | One hand-written stylesheet, `styles.css` (~600 lines). A few CSS variables on `:root`, dark theme only. |
| Data | `catalog.json` (68 products) fetched at start; everything else in `localStorage` / `sessionStorage`. |
| Offline | `sw.js` service worker (network-first for code/catalog, cache-first for images). |
| Hosting | GitHub Pages (`.nojekyll`). |
| Tests / lint / build | None exist. |

## Folder structure

```
./
├── index.html            all markup (login overlay, header, banner, 4 panels, tab bar, toast)
├── app.js                all behaviour: state, storage, rendering, roles, events
├── styles.css            all styling
├── sw.js                 service worker
├── catalog.json          product data
├── manifest.webmanifest  PWA manifest
├── icon-*.png, apple-touch-icon.png
└── thumbs/               68 product photos (400×400 JPG)
```

## Routing

There are no URL routes. "Screens" are four `<section class="panel">` elements toggled by
`switchTab()` in `app.js`, plus a full-screen login overlay. The tab buttons are
`.tab-btn[data-tab]`; `applyRole()` hides the ones a role may not open.

## Every screen

| # | Screen | Element | Who sees it | Contents |
|---|---|---|---|---|
| 1 | Sign in | `#loginScreen` | Everyone, until signed in | Role radio list, PIN input, inline error, Sign in button |
| 2 | Products | `#panel-products` | Manager, assistant, supervisor | Product photo grid grouped by category; tap to select, −/+ to set restock quantity |
| 3 | Stock | `#panel-stock` | All roles | Add-product form (editors only), summary line, "Restore removed" button, product rows with on-hand −/+ and Delete (editors only) |
| 4 | Par | `#panel-par` | Manager, assistant, supervisor | Help text, summary line, product rows with par −/+ |
| 5 | Restock | `#panel-restock` | All roles | Copy / Share / Clear buttons, selected-product rows with −/+ |

### Shared chrome and states

| Element | Notes |
|---|---|
| Header (`.app-header`) | Title, role label, Log out, total-units badge |
| Low-stock banner (`#lowBanner`) | Appears when any product is at or below par; Send reminder (mailto) and dismiss |
| Tab bar (`.tab-bar`) | Fixed bottom bar, emoji icons (📦 📋 🎯 🛒), badges for low count and restock count |
| Toast (`#toast`) | Short confirmation messages |
| Empty states | Restock "Nothing selected yet"; Stock/Par "No products" |
| Error state | "Couldn't load the product list" with Retry (catalog fetch failure) |
| Loading state | None — panels are blank until `catalog.json` arrives |

## Components (as built today)

Buttons (`.btn-primary/-secondary/-ghost/-danger/-sm`), quantity stepper (`.qty-row` + `.qty-btn`),
product card (`.product-card`), list row (`.restock-item`, `.stock-item`), low tag, badges,
section title, summary line, add-product form, role option, PIN field.

## Problems found

- Dark-only colour scheme; no light mode, no `prefers-color-scheme`.
- Emoji used as icons — inconsistent rendering across devices.
- No loading state; blank screen on slow networks.
- No focus styles beyond browser defaults (several were removed with `outline: none`).
- Tab-bar labels are 0.72rem (~11.5px) — small for a primary nav.
- Colours hard-coded in many rules (`#2a1820`, `#3a1c22`, `#333`, …) instead of tokens.
- Duplicate-name feedback on Add product is a toast only, not next to the field.
